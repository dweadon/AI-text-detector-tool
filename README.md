# AI-text-detector-tool
AI text detector tool. Naive Bayes technique based

## What is it?
This tool was built for checking whether text is AI or Human using Naive Bayes ML technique, although model is really raw and need more training, it still can detect short text for AI

## How to use it?
```Bash
git clone https://github.com/dweadon/AI-text-detector-tool
cd AI-text-detector-tool
python3 main.py
```
Although tool requiers sklearn, the sklearn installer is prebuilt in main.py, main.py will detect whether you have it installed and install it if you don't
